# mors_fsm_keyboard_control

Клавиатурное управление `FSMLocomotion` через `ros2lcm_bridge`. Старый пакет
`mors_keyboard_control` не используется и не изменяется.

## Сборка и запуск

Из корня репозитория:

```bash
source /opt/ros/jazzy/setup.bash
colcon build --base-paths ros_ws/src --packages-up-to mors_fsm_keyboard_control ros2lcm_bridge \
  --build-base ros_ws/build --install-base ros_ws/install
source ros_ws/install/setup.bash
export CONFIGPATH="$PWD/config"
export LCM_LOCOMOTION_URL='udpm://239.255.76.67:7667?ttl=1'
```

У FSM и моста должны совпадать LCM URL и `channels.yaml`. FSM нужен поток
`ROBOT_STATE` с флагами готовности. В отдельных терминалах запустите FSM,
мост и клавиатурный узел, предварительно настроив их окружение:

```bash
ros2 launch ros2lcm_bridge bridge.launch.py
```

```bash
ros2 run mors_fsm_keyboard_control mors_fsm_keyboard_control
```

Клавиатурный узел запускается в интерактивном терминале с TTY. При отсутствии
TTY ввод отключён. Сервисы совместимости моста `robot_mode` и `robot_action`
не нужны; пакет работает и с `legacy_services=false`.

Не запускайте одновременно другие источники `cmd_vel`, `cmd_pose`, `gait_params`
или команды режимов. В `fsm/result` нет идентификатора запроса, поэтому узел
должен быть единственным клиентом команд моста. Старые `mors_keyboard_control`,
`robot_mode_controller` и `ros2lcm` в этой цепочке не используются.

## Управление

| Клавиша | Действие |
|---|---|
| Enter | Встать из `PASSIVE`, иначе лечь через запрос `PASSIVE` |
| Space | Переключить управление `STANDING` / `LOCOMOTION` после вставания |
| W / S | Вперёд / назад |
| Q / E | Влево / вправо |
| A / D | Поворот против / по часовой стрелке |
| 1..9 | Скорость 0,1..0,9 м/с |
| Shift+1 (`!`) | `CHANGE_KINEMATICS`: `KNEE_INSIDE` (0) |
| Shift+2 (`@`) | `CHANGE_KINEMATICS`: `KNEE_OUTSIDE` (1) |
| Shift+3 (`#`) | `CHANGE_KINEMATICS`: `KNEE_BACK` (2) |
| Shift+4 (`$`) | `CHANGE_KINEMATICS`: `KNEE_FRONT` (3) |
| ↑ / ↓ | Высота корпуса ±0,002 м, диапазон 0,1..0,26 м |
| Ctrl+↑ / Ctrl+↓ | Длительность переноса ±0,01 с, минимум 0,01 с |
| Shift+↑ / Shift+↓ | Высота шага ±0,005 м, минимум 0 м |
| Ctrl+C | Завершить узел, отправить нулевую скорость |

Начальные значения сохранены: высота корпуса 0,206 м, высота шага 0,04 м,
перенос 0,18 с, скорость 0,3 м/с, смещения фаз `[0, 0.5, 0.5, 0]`.
Длительность опоры линейно уменьшается от 0,5 до 0,2 с с ростом выбранной
скорости от 0,1 до 0,9 м/с. Боковая скорость равна 0,6 от выбранной скорости,
скорость поворота равна удвоенному выбранному значению в рад/с.
Высота корпуса фильтруется с коэффициентом 0,2.

Для движения удерживайте клавишу. Команда обнуляется через 0,4 с после
последнего нажатия/автоповтора. При большой задержке начального автоповтора
возможна краткая остановка. Независимые направления можно совмещать.
Все три топика уставок публикуются с частотой 50 Гц, даже без изменения значений.

Смена кинематической схемы доступна только в `STANDING` без аварии. Сначала
остановите ходьбу через Space и дождитесь стойки. Shift+1…4 отправляют
`START_ACTION`, `target=CHANGE_KINEMATICS`, `params=0…3`. После завершения
действия управление остаётся в `STANDING`; ходьба вновь разрешается через Space.

Для Shift+1…4 используйте английскую (US) раскладку: узел распознаёт символы
`!`, `@`, `#`, `$`. В Terminator дополнительные настройки и плагины не нужны.
Обычные цифры 1…9 по-прежнему задают скорость.

## Состояние и ответы

Узел использует `fsm/command` (`mors_ros_msgs/srv/Command`), `fsm/state`
(`ModeState`) и `fsm/result` (`ModeResult`). Enter и Space отправляют по одному
`SET_MODE`, Shift+1…4 отправляют `START_ACTION`. Новые команды во время
незавершённой команды отклоняются
локально с сообщением в статусе, без очереди и автоматических повторов.

`control mode` отображает локальный режим управления; `LOCOMOTION` включается
только после `SUCCEEDED`. `FSM state` показывает фактическое состояние.
Разрешение `LOCOMOTION` допускает
автостарт по скорости, но без движения FSM может оставаться в `STANDING`.
При запуске и восстановлении связи разрешение ходьбы локально отключено:
после появления свежего статуса нажмите Space. Клавиши движения, нажатые до
подтверждения режима, не запоминаются.

При аварии, потере статуса или отказе команды скорость обнуляется.
`UNKNOWN` блокирует дальнейшие переключения до перезапуска клавиатурного узла.
Сначала проверьте фактическое состояние FSM и причину ошибки; если мост
сообщил о неопределённом результате, требуется также его перезапуск.
Узел не выполняет автоматический сброс аварии и не повторяет команды.

Параметры ROS:

| Параметр | По умолчанию | Назначение |
|---|---|---|
| `state_timeout` | 1,0 с | Допустимый возраст `fsm/state` |
| `command_timeout` | 35,0 с | Ожидание окончательного результата команды |

`command_timeout` задавайте больше `result_timeout` моста с запасом на доставку.
Ввод, публикация и контроль тайм-аутов используют монотонное время, включая
случай остановки ROS simulated time. При аварийном завершении процесса
обнуление скорости обеспечивает тайм-аут FSM.

## Проверка

```bash
colcon test --build-base ros_ws/build --install-base ros_ws/install \
  --packages-select mors_fsm_keyboard_control --event-handlers console_direct+
colcon test-result --test-result-base ros_ws/build/mors_fsm_keyboard_control
```

Тесты проверяют ввод, подтверждения и отказы команд, потерю статуса и передачу
команд через настоящий ROS/LCM-мост с отключёнными сервисами совместимости.
Интеграционный тест использует отдельный ROS domain и случайный LCM-порт.
