# Оценка положения корпуса робота по оси Z через кинематику опорных ног

## 1. Основное кинематическое соотношение

Для каждой ноги (i) положение стопы в мировой системе координат определяется выражением

[
{}^W\mathbf p_{F_i}
===================

{}^W\mathbf p_B
+
{}^W R_B,{}^B\mathbf p_{F_i},
]

где:

* ({}^W\mathbf p_{F_i}) — положение стопы в мировой системе координат;
* ({}^W\mathbf p_B) — положение корпуса робота в мировой системе координат;
* ({}^W R_B) — матрица поворота из системы координат корпуса в мировую систему;
* ({}^B\mathbf p_{F_i}) — положение стопы относительно корпуса, найденное с помощью прямой кинематики.

Для вертикальной координаты это выражение принимает вид

[
z_{F_i}
=======

z_B
+
\left(
{}^W R_B,{}^B\mathbf p_{F_i}
\right)_z.
]

Отсюда координата корпуса по оси (Z) может быть вычислена как

[
\boxed{
z_B
===

## z_{F_i}

\left(
{}^W R_B,{}^B\mathbf p_{F_i}
\right)_z
}
]

Таким образом, для расчёта высоты корпуса необходимо знать:

1. ориентацию корпуса;
2. положение стопы относительно корпуса;
3. высоту неподвижной точки контакта стопы.

---

## 2. Фиксация точки контакта

Когда нога касается поверхности, её положение в мировой системе координат фиксируется. Такая точка называется контактным якорем, или `contact anchor`.

Для вертикальной координаты сохраняется значение

[
z_{F_i}^{\text{anchor}}.
]

Пока нога находится в контакте с поверхностью и не проскальзывает, считается, что

[
z_{F_i}(t)
==========

z_{F_i}^{\text{anchor}}.
]

Тогда оценка высоты корпуса по данной ноге определяется выражением

[
z_B^{(i)}
=========

## z_{F_i}^{\text{anchor}}

\left(
{}^W R_B,{}^B\mathbf p_{F_i}
\right)_z.
]

Если робот изначально стоит на горизонтальной поверхности, для которой

[
z_{\text{ground}}=0,
]

то контактные якоря всех опорных ног могут быть инициализированы следующим образом:

[
z_{F_i}^{\text{anchor}}=0.
]

---

## 3. Расчёт по нескольким опорным ногам

Если с поверхностью одновременно контактируют несколько ног, каждая из них даёт собственную оценку высоты корпуса:

[
z_B^{(i)}
=========

## z_{F_i}^{\text{anchor}}

r_{F_i,z},
]

где

[
r_{F_i,z}
=========

\left(
{}^W R_B,{}^B\mathbf p_{F_i}
\right)_z.
]

Общая оценка высоты корпуса определяется как среднее значение по всем опорным ногам:

[
\boxed{
z_B
===

\frac{1}{N_c}
\sum_{i\in\mathcal C}
z_B^{(i)}
}
]

где:

* (\mathcal C) — множество опорных ног;
* (N_c) — количество опорных ног.

Для походки рысью в большинстве моментов времени высота корпуса оценивается по двум диагонально расположенным ногам.

---

## 4. Создание якоря для новой опорной ноги

Когда маховая нога касается поверхности, для неё необходимо создать новый контактный якорь.

Если текущая высота корпуса уже известна, вертикальная координата новой точки контакта определяется выражением

[
\boxed{
z_{F_j}^{\text{anchor}}
=======================

z_B
+
\left(
{}^W R_B,{}^B\mathbf p_{F_j}
\right)_z
}
]

Таким образом, вертикальная система координат последовательно переносится с одного набора опорных ног на другой.

Последовательность перехода выглядит следующим образом:

```text
Старые опорные ноги
        ↓
Расчёт высоты корпуса z_B
        ↓
Обнаружение касания новой ноги
        ↓
Создание нового contact anchor
        ↓
Отрыв старой опорной ноги
```

Важно сначала вычислить высоту корпуса по уже существующим контактам и только после этого создавать якорь для новой ноги.

---

## 5. Полный алгоритм

На каждом такте управления выполняются следующие действия.

### Шаг 1. Расчёт положения стоп относительно корпуса

Для каждой ноги с помощью прямой кинематики вычисляется положение стопы:

[
{}^B\mathbf p_{F_i}
===================

FK_i(q_i),
]

где (q_i) — вектор суставных координат ноги.

### Шаг 2. Переход в мировую систему координат

Вектор от корпуса до стопы поворачивается в мировую систему:

[
{}^W\mathbf r_{F_i}
===================

{}^W R_B,{}^B\mathbf p_{F_i}.
]

Из него используется вертикальная составляющая

[
r_{F_i,z}
=========

\left(
{}^W\mathbf r_{F_i}
\right)_z.
]

### Шаг 3. Расчёт высоты корпуса по каждой опорной ноге

Для каждой ноги, которая находится в контакте и имеет действительный контактный якорь, вычисляется

[
z_B^{(i)}
=========

## z_{F_i}^{\text{anchor}}

r_{F_i,z}.
]

### Шаг 4. Усреднение оценок

Если имеется хотя бы одна опорная нога, итоговая высота корпуса определяется как

[
z_B
===

\frac{1}{N_c}
\sum_{i\in\mathcal C}
z_B^{(i)}.
]

### Шаг 5. Создание якорей для новых контактов

Для ноги, которая только что перешла из фазы переноса в фазу опоры, вычисляется

[
z_{F_i}^{\text{anchor}}
=======================

z_B+r_{F_i,z}.
]

### Шаг 6. Сброс якорей оторвавшихся ног

Если нога перестала контактировать с поверхностью, её якорь помечается как недействительный.

## 6. Псевдокод

```cpp
struct FootContactAnchor
{
    bool valid = false;
    double z_world = 0.0;
};

double estimateBaseZ(
    const Eigen::Matrix3d& R_world_base,
    const std::array<Eigen::Vector3d, 4>& foot_pos_base,
    const std::array<bool, 4>& contact,
    const std::array<bool, 4>& touchdown,
    std::array<FootContactAnchor, 4>& anchors,
    double previous_base_z)
{
    std::array<double, 4> foot_relative_z;

    // Вычисление вертикального положения стоп
    // относительно корпуса в мировой системе координат.
    for (int i = 0; i < 4; ++i)
    {
        const Eigen::Vector3d foot_offset_world =
            R_world_base * foot_pos_base[i];

        foot_relative_z[i] = foot_offset_world.z();
    }

    double base_z_sum = 0.0;
    int valid_contact_count = 0;

    // Расчёт высоты корпуса по уже существующим опорам.
    for (int i = 0; i < 4; ++i)
    {
        if (contact[i] && anchors[i].valid)
        {
            const double base_z_from_foot =
                anchors[i].z_world - foot_relative_z[i];

            base_z_sum += base_z_from_foot;
            ++valid_contact_count;
        }
    }

    double base_z = previous_base_z;

    if (valid_contact_count > 0)
    {
        base_z =
            base_z_sum /
            static_cast<double>(valid_contact_count);
    }

    // Создание якорей для новых контактов.
    for (int i = 0; i < 4; ++i)
    {
        if (touchdown[i])
        {
            anchors[i].z_world =
                base_z + foot_relative_z[i];

            anchors[i].valid = true;
        }

        if (!contact[i])
        {
            anchors[i].valid = false;
        }
    }

    return base_z;
}
```

## 7. Инициализация алгоритма

Если робот включается в неподвижном состоянии и стоит на плоской поверхности, можно считать высоту поверхности равной нулю:

[
z_{\text{ground}}=0.
]

Тогда для всех ног, находящихся в начальном контакте, задаётся

[
z_{F_i}^{\text{anchor}}=0.
]

Начальная высота корпуса вычисляется как

[
z_B
===

-\frac{1}{N_c}
\sum_{i\in\mathcal C}
\left(
{}^W R_B,{}^B\mathbf p_{F_i}
\right)_z.
]

Если поверхность неровная, начальные высоты стоп должны быть получены из карты высот или заданы относительно выбранного начального уровня.

## 8. Пример расчёта

Пусть положение стопы относительно корпуса равно

[
{}^B\mathbf p_F
===============

\begin{bmatrix}
0.1\
0.07\
-0.22
\end{bmatrix}
\text{ м}.
]

Корпус расположен горизонтально, поэтому

[
{}^W R_B=I.
]

Стопа находится на поверхности с высотой

[
z_F^{\text{anchor}}=0.
]

Тогда

[
z_B
===

# 0-(-0.22)

0.22\text{ м}.
]

Если корпус имеет ненулевые углы крена или тангажа, необходимо использовать полную матрицу поворота:

[
z_B
===

## z_F^{\text{anchor}}

\left(
{}^W R_B,{}^B\mathbf p_F
\right)_z.
]

Использовать только локальную координату

```cpp
foot_pos_base.z()
```

нельзя, поскольку при наклоне корпуса вертикальная проекция положения стопы изменяется.

---

## 9. Ограничения алгоритма

Чисто кинематический метод может определить положение корпуса по оси (Z) только при наличии хотя бы одной действительной неподвижной точки контакта.

Метод не может корректно обновлять абсолютную высоту в следующих ситуациях:

* робот находится в фазе полёта;
* все ноги признаны маховыми;
* робот подняли руками;
* все контактные якоря были сброшены;
* опорные ноги проскальзывают;
* контакт определён ошибочно.

Если действительных контактов нет, без дополнительных источников информации остаётся только сохранить предыдущее значение:

```cpp
if (valid_contact_count == 0)
{
    base_z = previous_base_z;
}
```

При обычной ходьбе, когда хотя бы одна нога остаётся в надёжном контакте, алгоритм работает как последовательный перенос вертикальной координаты через контактные якоря.
